## 0. Scope & Honesty Statement

This batch contains **54 rules** extracted from live web sources for WHO, AHA, ADA, NHLBI, ACSM, ISSN, and ICMR-NIN, gathered on 2026-08-03. The original roadmap targets 150–200 rules — **that target is not met in this batch**. Rather than pad the count with invented or loosely-sourced items, this batch only includes recommendations I could trace to a specific, named, currently-live source.

What this means practically:
- Every rule below has a real organization, a real document, and a URL you can check.
- Where a rule gives a specific number (e.g., "≥400 g/day"), that number is taken directly from the source, not estimated.
- Page numbers are **NOT SUPPORTED BY PROVIDED SOURCES** in most cases below, because these sources are live web pages/fact sheets, not paginated PDFs I fetched with page markers. Where a source is a PDF with visible page/section structure, I've noted the section name instead of a page number. I did not invent page numbers — per your framework, that would be a fabrication.
- Several important documents (full AHA 2021/2026 scientific statement, full ACSM/ISSN PDFs, full ICMR-NIN manual) exist as long PDFs I only partially accessed via search snippets and one fetch. A future batch should fetch these PDFs directly (via upload or direct fetch) for exact page-numbered citations suitable for a thesis-defensible rulebook.
- No rule in this batch is Expert Opinion alone dressed up as high evidence — I've marked evidence strength per the classification scheme you defined (HIGH/MODERATE/LOW), based on document *type*, not content quality I judged myself.

To reach 150–200 rules with the same rigor, later batches should pull additional sub-guidelines per organization (e.g., WHO's individual guideline documents on sugars, sodium, potassium, trans fat, complementary feeding — each is a separate publication with its own rule set) rather than trying to extract everything from one fact sheet per org.

## 3. Conflicting Evidence

| Conflict ID | Topic | Source A | Source B | Nature of Disagreement | Clinical/Implementation Implication |
|---|---|---|---|---|---|
| CONF-01 | Exact sodium ceiling | WHO: <5 g salt/day (<2,000 mg sodium) — Guideline: Sodium intake for adults and children, 2012 | NHLBI DASH: 2,300 mg sodium/day standard target (1,500 mg for greater effect) | WHO's blanket population target (<2,000 mg sodium) is stricter than NHLBI's standard DASH target (2,300 mg), though NHLBI's *stricter* DASH-Sodium arm (1,500 mg) is stricter than WHO's. The organizations are not contradicting the *direction* of the recommendation, but their default numeric targets differ by ~300 mg/day. | An app cannot silently pick one number as "the" WHO-and-NHLBI-endorsed threshold. Implementation should either (a) surface both values with attribution, or (b) let the treating clinician/dietitian select the applicable target, especially for DASH-prescribed hypertensive patients vs. general wellness users. |
| CONF-02 | Protein supplementation for muscle building | ISSN: Protein per serving of 20–40 g / 0.25 g/kg to maximize muscle protein synthesis; supplementation described as "a practical way of ensuring adequate protein intake" for physically active individuals (2017 Position Stand) | ICMR-NIN 2024: "avoid protein supplements to build muscle mass," recommending food-based protein combinations instead | Direct disagreement on whether *supplemental* (as opposed to whole-food) protein is an appropriate strategy for muscle building in generally active/exercising individuals. | This is a genuine, population-relevant conflict, not just phrasing. Possible reconciling factors (untested by provided sources): ICMR-NIN's guidance targets the **general Indian population**, including sedentary/non-athlete users, while ISSN's guidance targets **exercising/athletic individuals with elevated protein needs and adequate food-based intake as an alternative**. **This distinction is NOT explicitly confirmed by either source** — it is a plausible interpretation, not a supported synthesis, so it must be flagged, not resolved, in the knowledge base. |

NUT-WHO-15 (Salt/sodium limit)

↓
Engineering Rule: Estimated Daily Salt Intake ≥ 5 g
↓
Implementation Rule:
  IF estimated_daily_salt_g >= 5
  THEN generate_alert("sodium_reduction_guidance", evidence_ref="NUT-WHO-15")
```

```
NUT-NHLBI-01 (DASH sodium ceiling)
Clinical Rule: For blood-pressure benefit, sodium intake should not exceed 2,300 mg/day.
↓
Engineering Rule: Estimated Daily Sodium (mg) > 2300
↓
Implementation Rule:
  IF estimated_daily_sodium_mg > 2300
  THEN generate_alert("dash_sodium_guidance", evidence_ref="NUT-NHLBI-01")
  NOTE: MANUAL REVIEW REQUIRED if user has a clinician-prescribed DASH 1500mg target (NUT-NHLBI-02) — do not silently override a prescribed target with the population default.
```

```
NUT-ISSN-01 (Daily protein for exercising individuals)
Clinical Rule: Exercising individuals should consume 1.4–2.0 g protein/kg body weight/day.

## 7. Recommendations Requiring MANUAL REVIEW (Legal/Clinical Risk if Automated)

| Rule ID | Reason for manual review flag |
|---|---|
| NUT-ADA-01, NUT-ADA-02, NUT-ADA-03 | Involves diagnosed diabetes/prediabetes + specific weight-loss percentage targets. Automating a numeric weight-loss target for a diagnosed condition without clinician oversight crosses from "wellness guidance" into "treatment planning." |
| NUT-ADA-07 | Involves nutritional monitoring during pharmacotherapy (e.g., GLP-1-class drugs) — an app should not autonomously adjust nutrition guidance in a way that could mask or interact with medication-related risk (e.g., protein insufficiency during rapid weight loss). |
| NUT-ISSN-01 through 11, when applied to a user with any disclosed kidney, liver, or metabolic condition | Elevated protein intake recommendations are stated by ISSN as safe **in healthy, active persons**; the source population is not people with renal impairment. Applying these rules to users with undisclosed or disclosed kidney disease is unsupported and potentially harmful. |
| NUT-WHO-15 / NUT-NHLBI-01/02 vs. any user on a clinician-prescribed sodium target | An app must never silently override an individually prescribed sodium target (e.g., a nephrologist's 1,500 mg limit, or conversely a clinician-approved higher limit for a specific condition) with a population-level default. |
| CONF-02 (protein supplement conflict) | Because the sources directly disagree, no automated "supplement: yes/no" recommendation should be generated without a human-reviewed policy decision on which population default applies. |

## 8. Safe for Automation (No Manual Review Required) — This Batch
